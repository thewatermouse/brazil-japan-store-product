# Nippon Brasil Select

Base project for a direct-to-consumer ecommerce operation selling compact Brazilian products into Japan.

## Positioning

- Consumer-facing storefront focused on Japan
- Merchant and fulfillment operated by Melinda & Julius Comercio de Alimentos
- Initial products: propolis, coffee, acai powder and similar shelf-stable items

## Stack

- Next.js 15
- React 19
- TypeScript
- Custom CSS

## Run locally

```bash
npm install
npm run dev
```
